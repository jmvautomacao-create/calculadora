# Calculadora Do Jean

Calculadora científica com interface gráfica desenvolvida em Python usando Tkinter.

## Funcionalidades

- **Operações básicas:** soma, subtração, multiplicação, divisão
- **Operações científicas:** seno, cosseno, tangente, logaritmo (log/ln), raiz quadrada, potência (x²), inverso (1/x), π e
- **Porcentagem:** cálculos com % (acréscimo, desconto, multiplicação e divisão percentual)
- **Memória:** MC, MR, M+, M-, MS
- **Teclado:** suporte a digitação pelo teclado físico
- **Display:** entrada e exibição de expressões em tempo real

## Requisitos

- Python 3.x
- Tkinter (já incluso na instalação padrão do Python)

## Como usar

```bash
python calculadora3.py
```

## Atalhos do teclado

| Tecla          | Ação         |
|----------------|--------------|
| `0-9`          | Números      |
| `+ - * /`      | Operadores   |
| `.`            | Ponto decimal |
| `Enter`        | Calcular     |
| `Backspace`    | Apagar último caractere |
| `Esc`          | Limpar (C)   |
